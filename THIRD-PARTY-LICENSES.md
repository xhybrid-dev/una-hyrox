# Third-Party Licences

The MIT licence in [`LICENSE`](LICENSE) covers **HybridX's own source code** in
this repository: everything under `hybridx-race/Software/`, `hybridx-race/Tests/`
and `hybridx-race/docs/`.

It does **not** cover the third-party components the built `.uapp` links, nor the
generated font data this repository redistributes. Those keep their own terms.

## What the `.uapp` links

The app is a position-independent ELF that statically links the UNA Watch SDK
and, for the GUI process, LVGL. Nothing under the SDK's `ThirdParty/touchgfx/`
is linked — the GUI is LVGL, and `HybridXRaceGUI.elf.elf.map` contains no
TouchGFX symbols. That matters, because TouchGFX's SLA0048 forbids subjecting it
to open-source terms, and the HybridX Race binary is not subject to it.

| Component | Version | Licence |
|---|---|---|
| UNA Watch SDK | `apps-v1.5.0-rc4-8-ga7a995a1` | **MIT** — UNA Watch Ltd. The MIT licence grants no trademark rights; see the SDK's `TRADEMARK.md` |
| LVGL | v9.5.0 | **MIT** — LVGL Kft, see the SDK's `ThirdParty/lvgl/LICENCE.txt` |
| coreJSON | as vendored by the SDK | **MIT** |
| tinycbor | as vendored by the SDK | **MIT** — Intel Corporation |

## What this repository redistributes

`hybridx-race/Software/Apps/LVGL-GUI/assets/fonts/*.c` are LVGL bitmap fonts
generated by `lv_font_conv` from the **Poppins** typeface. They are checked in
rather than generated at build time, which makes them a redistributed derivative
of the font, not just a build artifact.

Poppins (Indian Type Foundry, Jonny Pinhorn) is published under the **SIL Open
Font License 1.1**, which permits this and requires the copyright notice and
licence to travel with the derivative.

> **Open item for Jon before publishing.** The SDK checkout ships the Poppins
> TTFs (`Docs/Tutorials/Buttons/Software/Apps/TouchGFX-GUI/assets/fonts/`)
> **without a licence file**, and the SDK's own `THIRD-PARTY-LICENSES.md` names
> TouchGFX, coreJSON and tinycbor but neither LVGL nor Poppins. So the statement
> above rests on Poppins' public licensing rather than on anything in the
> checkout. Before the app is published under either route, confirm the licence
> that applies to the TTFs the SDK distributes and, if OFL, add `OFL.txt` beside
> the generated fonts. This is logged in `hybridx-race/docs/NOTES.md` 5.5.
